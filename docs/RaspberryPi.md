# Raspberry Pi (Setup)

## Installation

1. Betriebssystem installieren: Die MicroSD-Karte mithilfe eines Kartenlesers und des Raspberry Pi Imager mit Ubuntu 24.04.5 LTS flashen und anschließend den Raspberry Pi starten. Dabei eine Netzwerkverbindung herstellen, einen Benutzer anlegen usw.
2. ROS 2 installieren: Die Installation gemäß der offiziellen Anleitung durchführen: [ROS 2 Jazzy – Installation unter Ubuntu](https://docs.ros.org/en/jazzy/Installation/Ubuntu-Install-Debs.html).
